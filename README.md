# 💫 About Me:
I’m an Associate Software Developer and User Experience Officer passionate about building digital products that blend performance, precision, and great design. I specialize in crafting intuitive, high-performing mobile interfaces using Flutter and Dart, combining modern design principles with scalable, maintainable architecture.<br>My work focuses on bridging the gap between design and development—ensuring that every feature not only functions flawlessly but also feels seamless to use. I’ve implemented complex app components such as camera integration, polygon drawing, and map functionality, while maintaining clean, modular code using the MVVM architecture.<br>Beyond app development, I bring hands-on experience from Nothing as a User Experience Officer, where I conduct alpha and performance testing for IoT devices—including smartwatches, earbuds, and headphones.
