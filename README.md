# 💫 About Me:
I’m an Associate Software Developer passionate about building digital products that balance performance, precision, and thoughtful design. I specialize in crafting intuitive, high-performing mobile applications using Flutter and Dart, applying modern UI principles alongside scalable and maintainable architecture.
